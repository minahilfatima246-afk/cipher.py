# cipher.py
A beginner-friendly Python Caesar Cipher tool that allows users to encrypt and decrypt messages, perform brute force attacks, and crack encrypted text using frequency analysis. Built to explore cryptography and Python programming concepts
# features
Encryption: Convert plain text into encrypted message
Decryption: Restore encrypted messages using a shift key
Brute Force: Test all 26 possible shifts to decode a message
Auto Crack: Guess the encryption key using letter frequency analysis
Input Validation: Handle invalid choices and keys
# Technologies used 
Python 3
Collections (Counter)
String module

# How it Works
The Caesar Cipher shifts each letter in a message by a specified number of positions in the alphabet
Example
Original message: HELLO
Shift key: 3
Encrypted message: KHHOR
